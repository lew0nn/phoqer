# License texts

These are verbatim license texts for third-party components used by current
PHOQER plug-in builds. They are collected here so binary packages can carry
the required notices without depending on a developer checkout.

The root `LICENSE` controls only original PHOQER material. This directory does
not change the scope or terms of any third-party license. Embedded notices in
third-party source files must also be preserved.

See `../THIRD_PARTY_NOTICES.md` for component revisions, scope, and the ASIO
standalone-build restriction.
