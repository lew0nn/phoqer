# Contributing to PHOQER

Bug reports, testing notes, and feature discussions are welcome.

PHOQER does not currently accept third-party code, DSP, artwork, samples,
presets, or other copyrightable material for inclusion in the main repository.
Please do not open a pull request containing such material unless the project
owner has first agreed in writing to contributor terms for that contribution.

This policy protects both contributors and the project: PHOQER's owner must be
able to maintain the public source-available license and offer separate
commercial licenses without accidentally claiming rights that a contributor
did not grant. Opening an issue or discussing an idea does not transfer
copyright. A pull request alone does not grant the project owner relicensing
rights and will not be merged without a separate written contributor agreement.

When contributor support is introduced, the agreement will identify the exact
contribution and preserve the contributor's copyright while granting the
project owner sufficient rights to use, modify, distribute, sublicense, and
relicense it. Until then, keep proposed code and assets out of issues and pull
requests; describe the behavior or problem instead.

By submitting a bug report or other non-code feedback, you permit the project
to use the factual information and ideas in that report. This does not assign
copyright in any attached creative material.
