# PHOQER

A synthetic MIDI instrument built around seal-like barks, groans, and vocal calls.

PHOQER generates its sound in real time. Recorded calls are sound-design references;
the instrument does not play back seal samples.

Built with C++17 and JUCE 8.0.8. Current targets are VST3 and Standalone for Windows x64.

## Development status

PHOQER is an early work in progress. Its engine works and all three sound characters
speak, but the interface is still being refined before the first public release.

Three sound characters, each with its own synthesis:

- **SQUEAL:** the default. Bright, piercing bursts with a falling then rising pitch gesture.
- **BURP:** the bass voice. Low and rough, built on irregular period doubling.
- **GROAN:** the high voice. Pure and sustained, with a slow swell and one narrow singing formant.

Sound is generated by formant-wave-function synthesis, the technique behind Chant and
Delay Lama, in which each vocal resonance is built from overlapping grains rather than
filtered noise. Each character has eight-voice polyphony, holds a note for as long as you
hold the key, and is shaped from a table of formant frequencies, bandwidths and pitch
contours measured from recorded seal calls.

Each character owns one visual identity: SQUEAL is Purple, BURP is Red, GROAN is Ice.
The editor also includes a live waveform and output meter.

## Controls

BOOM, AIR, BARK, SPACE, and TIDE are exposed in the main interface. VOWEL, DETUNE,
OUTPUT, CHARACTER, and BEHAVIOR are stable host parameters but have no on-screen control
yet. Detune and reverb start at zero.

Output is level-managed: one note at full velocity peaks near -10 dBFS and a safety
limiter holds the ceiling at -0.3 dBFS, so the output gain can be pushed without clipping.

## Build from source

Requirements: Git, CMake 3.22 or newer, Visual Studio 2022 with the **Desktop development
with C++** workload, and a Windows SDK.

```powershell
git clone --recurse-submodules https://github.com/lew0nn/phoqer.git
Set-Location phoqer
cmake -S . -B Build-JUCE -G "Visual Studio 17 2022" -A x64
cmake --build Build-JUCE --config Release --target PHOQER_VST3 PHOQER_Standalone
```

The results are written below `Build-JUCE/PHOQER_artefacts/Release/`. Copy the complete
`PHOQER.vst3` bundle to a VST3 directory scanned by your host, then rescan plug-ins.

The repository path should not contain parentheses because JUCE's Windows binary-data
generator is passed through MSBuild command files.

For engine details, see [README_DEV.md](README_DEV.md).
