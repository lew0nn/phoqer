# PHOQER

A synthetic MIDI instrument built around seal-like barks, groans, and vocal calls.

PHOQER generates its sound in real time. Recorded calls are sound-design references;
the instrument does not play back seal samples.

Built with C++17 and JUCE 8.0.8. Current targets are VST3 and Standalone for Windows x64.

## Development status

PHOQER is in beta: everything works, the sound and the interface are still being tuned
before the first official release.

Three seals, each with its own voice and colours:

- **BURP** (red): the default. A low, rough bass bark; the growl comes from jitter and
  period doubling, not breath.
- **SQUEAL** (purple): short bright yelps that start high, drop, then lift again.
- **GROAN** (ice): a long, warm "ooh" moan that scoops up into the note, with a slow vibrato.

Sound is generated by formant-wave-function synthesis, the technique behind Chant and
Delay Lama, in which each vocal resonance is built from overlapping grains rather than
filtered noise. PHOQER plays eight notes at once, holds a note for as long as you hold the
key, and shapes each seal from a table of formant frequencies, bandwidths and pitch
contours measured from recorded seal calls.

## Controls

Every control is on screen:

| Knob | What it does |
|---|---|
| BOOM | The seal's size: small, or big with more chest |
| AIR | Breath, from none at all |
| BARK | Attack and growl: a soft swell to a hard hit |
| SPACE | Reverb: dry to a big dark cave |
| VOWEL | OO, OH, AH, EH, EE |
| DETUNE | Width: one voice to a wide double |
| TIDE | Expression: a straight note to scoops and vibrato |
| OUTPUT | The level |

Five modes set how a held note behaves. HONK, BARK and WAIL keep time with the song's
tempo (120 BPM in the standalone app):

| Mode | What it does |
|---|---|
| CALL | One call per note |
| HONK | Nasal honks on 1/8 notes while the key is held |
| BARK | Hard barks on 1/4 notes while the key is held |
| WAIL | A long glide up and back over two bars |
| MURMUR | A muttered, closed-mouth hum |

MIDI: velocity, pitch bend (two semitones), the sustain pedal (CC 64), and the mod wheel
(CC 1), which adds TIDE on top of the knob.

The menus hold undo and redo, presets, copying and pasting settings, reverting to the
last save, a panic button, the controls guide and keyboard shortcuts. KEYS.EXE turns the
computer keyboard into a piano, and REC records what you play to a WAV file.

Output is level-managed: one note at full velocity peaks near -10 dBFS and a safety
limiter holds the ceiling at -0.3 dBFS, so the output gain can be pushed without clipping.

## Build from source

Requirements: Git, CMake 3.22 or newer, Visual Studio 2022 with the **Desktop development
with C++** workload, and a Windows SDK.

```powershell
git clone --recurse-submodules https://github.com/lew0nn/phoqer.git
Set-Location phoqer
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --target PHOQER_VST3 PHOQER_Standalone
```

The results are written below `build/PHOQER_artefacts/Release/`. Copy the complete
`PHOQER.vst3` bundle to a VST3 directory scanned by your host, then rescan plug-ins.

The repository path should not contain parentheses because JUCE's Windows binary-data
generator is passed through MSBuild command files.

For engine details, see [README_DEV.md](README_DEV.md).
