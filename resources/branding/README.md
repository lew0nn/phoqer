# PHOQER branding

Pixel-art brand marks in the flat synthwave voice palettes (BURP, SQUEAL, GROAN). Everything here is
generated by `Tools/branding/phoqer_branding.py` (needs numpy and Pillow); edit the script, not the PNGs.

## App logo: `app/`

The **seal sun** icon (the striped sun is the seal's face) with the slanted **Outrun** PHOQER wordmark.

| File | Use |
| --- | --- |
| `phoqer-app-icon-16.png`, `phoqer-app-icon-256.png` | `.exe` / plugin icon (`ICON_SMALL` / `ICON_BIG` in `CMakeLists.txt`). The 256 px file is the 32 px design at 8x, so Windows' 32 px icon stays pixel-exact. SQUEAL palette. |
| `phoqer-logo-<voice>.png` | Icon + wordmark lockup at 4x, for docs and README use. |

The Test UI draws the same logo live from `Source/TestUI/TestUiLogo.cpp` (header and taskbar Start
button), recoloured per voice. Keep it in step with the script.

## Website: `website/`

The **sunset grid** mark (seal silhouette on the horizon, striped sun, neon floor) is reserved for the
product web page.

| File | Use |
| --- | --- |
| `phoqer-site-icon-<voice>-512.png` | The mark on its own, 32 px design at 16x. |
| `phoqer-site-hero-<voice>.png` | 1200 x 630 hero / social card: mark + wordmark on the night sky. |
