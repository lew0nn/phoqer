# PHOQER branding

Pixel-art brand marks in the flat synthwave voice palettes (BURP, SQUEAL, GROAN). Everything here is
generated by `Tools/branding/phoqer_branding.py` (needs numpy and Pillow); edit the script, not the PNGs.

## App logo: `app/`

The app icon is a framed tile: the seal's face is the synthwave sun, sitting on a calm sea, with soft
whiskers. Small sizes (up to 32 px) show the round head; large sizes (48 px and up) use a separate
drawing where the neck widens into shoulders at the waterline, so the head doesn't read as a ball.
It pairs with the slanted **Outrun** PHOQER wordmark.

| File | Use |
| --- | --- |
| `phoqer-app-icon.ico` + `phoqer-app-icon.rc` | Windows `.exe` icon: 16, 20, 24, 32, 40, 48, 64 and 256 px, each drawn for its size. BURP palette (the default voice). |
| `phoqer-app-icon-32.png`, `phoqer-app-icon-256.png` | `ICON_SMALL` / `ICON_BIG` for the macOS and Linux builds (see `CMakeLists.txt`). |
| `phoqer-logo-<voice>.png` | Large icon + wordmark lockup, for docs and README use. |

The editor draws the small icon live from `Source/UI/Logo.cpp`, recoloured per voice; next
to the wordmark in the header it is shown without the coloured frame. Keep it in step with the script.

## Website: `website/`

The **sunset grid** mark (seal silhouette on the horizon, striped sun, neon floor) is reserved for the
product web page.

| File | Use |
| --- | --- |
| `phoqer-site-icon-<voice>-512.png` | The mark on its own, 32 px design at 16x. |
| `phoqer-site-hero-<voice>.png` | 1200 x 630 hero / social card: mark + wordmark on the night sky. |
